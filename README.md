The website is similar to many popular Chatbots, such as ChatGPT, Claude, etc. So you'll most likely be familiar with the structure & usage.

## Usage

Fill in:
1. Your **free** [API Key from GROQ](https://console.groq.com/keys) (using the url provided).
2. And your cloudfare worker url, to get around blocking. Which you can get below:
  * By forking this [SimpleProxy-2.0](https://github.com/Gladimore/SimpleProxy-2.0)
  * Then going to [Cloudflare](https://dash.cloudflare.com/)
  * Logging in/signing up
  * On /home/overview, press the blue, "Add" button, then on the list that pops up: press "Workers"
  * Continue with Github
  * Select the forked repository (most likely under the name: "SimpleProxy-2.0")
  * Deploy

###### Everything is saved locally.
### Cloudflare Workers is heavily optimized, with a median latency of 0.5ms on the provided proxy.
